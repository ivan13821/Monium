# Monium
Эта библиотека для работы с Monium из Yandex Cloud. Она позволяет упрощенно записывать логи и метрики. Внутри используется протокол OpenTelemetry

## Скорость
Внутри библиотеки используются асинхронные вызовы для получения IAM-токена и API-ключей, также обновление и удаление происходит также асинхронно.
API-ключе кэшируются, т.е если какой-либо ключ из существующих содержит нужный набор ролей, тогда отдается этот ключ. 
Т.е набор ролей существующего ключа должен включать в себя набор ролей искомого ключа

## Безопасность
Для безопасности применяется несколько мер защиты:
1. Ротация IAM-токенов. Токен, имеет малый срок жизни, по умолчанию - 1 час, после чего он становится недействительным и обновляется.
2. Ротация API-ключей. API-ключ создается с минимальными правами, которые запрашивает пользователь, также по истечению срока жизни ключа, ключ удаляется из облака и создается новый
3. Если запуск программы происходит на ВМ Yandex Cloud, тогда библиотека автоматически получается IAM-токен из метаданных ВМ

## Использование
Для начала нужно настроить класс для работы с токенами:
```python
from monium_sdk.security import ServiceAccountConfigData, Tokens

config = ServiceAccountConfigData(
    service_account_id="Идентификатор сервисного аккаунта",
    private_key="Приватный ключ для сервисного аккаунта",
    key_id="Идентификатор ключа"
)

# Если вы используете файл полученный из Yandex Cloud тогда, можете указать его:

config_path = ServiceAccountConfigData(
    patch="путь/до/файла"
)

Tokens.service_account_config = config_path
```

После этого вы можете использовать весь функционал библиотеки
```python
import asyncio
from monium_sdk import Telemetry


async def test():
    log = await Telemetry.get_log_manager()
    log.info("First message")


if __name__ == "__main__":
    asyncio.run(test())
```
